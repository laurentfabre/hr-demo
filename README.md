# HR Demo — People Intelligence on Databricks

A bilingual (FR/EN) Databricks App demo for HR leaders: governed self-service,
workforce capacity decisions, group reconciliation, Genie agents and an audited,
human-reviewed action loop. **All data is synthetic.**

**→ Start with the field guide: [`docs/index.html`](docs/index.html)**. Open it in
a browser. It explains every route, the 5/10/20-minute demo paths, the talk
track, objections, architecture, deployment and fallback, with screenshots.

## Quick start

```sh
uv sync --project app
cp target.example.json target.local.json   # fill in profile, presenter, Lakebase, model
PY=app/.venv/bin/python
$PY delivery/manage.py preflight --profile <p> --config target.local.json --out runs/01-preflight.json
$PY delivery/manage.py provision --profile <p> --config target.local.json --out runs/02-provision.json
$PY delivery/manage.py deploy    --profile <p> --config target.local.json --out runs/03-deploy.json
$PY delivery/manage.py verify    --profile <p> --config target.local.json --out runs/04-verify.json
```

Then open `/enterprise` in the App and click **New rehearsal**.

| Path | What |
|---|---|
| `docs/` | Field guide (HTML), screenshots, recorded fallback walkthrough |
| `app/` | APX app (FastAPI + React), prebuilt wheel in `app/.build/` |
| `delivery/` | Lifecycle (`manage.py`), simulated GCP source, external tool client, `FIELD_GUIDE.md`, detailed `README.md` |
| `platform/` | Optional reference scripts for the Genie / DNB agents (adapt first) |
| `MANIFEST.json` | SHA-256 of every packaged file + source commit |

Deployment details, identity model and day-two ownership:
[`delivery/README.md`](delivery/README.md). Presenter cheat sheet:
[`delivery/FIELD_GUIDE.md`](delivery/FIELD_GUIDE.md).

Never use a production HR database or real employee data. `*.local.json` and
`.env*` are gitignored. Do not commit target configs or tokens.

The guide HTML is generated by `docs/src/build.py` from the Socomec site template
CSS. Edit `docs/src/guide.body.html`, not `docs/index.html`.
